faq:
  - q: 为什么突然间所有节点在测速时全部显示 Timeout（超时）？
    a: 全部节点同时超时最常见原因有三个：① 电脑/手机系统本地时间偏差超过 60 秒（VLESS/Trojan 对时间戳校验极严）；② 电脑同时开了游戏加速器、公司 VPN 或残留了错误端口；③ 机场更换了入口 IP/域名，本地旧订阅未更新。
  - q: 节点测速有绿色延迟，但点开网页依然打不开怎么办？
    a: 这是典型的“DNS 污染或 Fake-IP 缓存残留”表现。检查浏览器是否开启了自带安全 DNS（DoH）绕过了客户端接管，或者刷新系统 DNS 缓存（Windows 运行 ipconfig /flushdns）并重启浏览器。
  - q: 点击“更新订阅”一直报 Network Error、403 或解析失败怎么处理？
    a: 若订阅域名被本地宽带临时阻断，可先用手机 4G/5G 热点更新一次，或在 Clash Verge Rev 订阅设置中勾选“通过代理更新”；另外检查是否把 V2Ray Base64 链接直接填进了要求 YAML 格式的输入框，或者误买了不开放订阅的专属端品牌。
  - q: 关闭代理客户端之后，电脑连百度、微信都打不开了怎么恢复？
    a: 说明客户端异常退出时未能自动清理 Windows 系统代理设置，或浏览器残留了 Fake-IP (198.18.0.x) 缓存。打开 Windows“设置 → 网络和 Internet → 代理”，手动关闭“使用代理服务器”，然后重启浏览器即可恢复。
  - q: 开启 Clash Verge Rev 的 TUN 模式后反而全部断网是什么原因？
    a: 常见于未成功安装 Service Mode（服务模式）、与系统防火墙/杀毒软件冲突，或同时运行了 EasyConnect/WireGuard/游戏加速器等另一套虚拟网卡驱动。详细解决步骤见 /diagnostics/clash-tun-conflict。
  - q: 测速截图明明能跑 500Mbps，为什么我家 500M 宽带实际下载只有几 MB/s？
    a: 一方面测试图多为机房 2Gbps–9Gbps 多线程环境测出的节点峰值；另一方面 2026-10-19 汇总表为非晚高峰测试，晚间 20:30–22:30 家宽可能遇到本地 Wi-Fi 瓶颈、运营商 QoS 或浏览器 QUIC UDP 冲突。尝试关闭 Chrome 的 QUIC 或切换新加坡/日本节点对照。
  - q: 手机锁屏一会代理就断开，必须重新点连接怎么办？
    a: 这是安卓/iOS 系统后台省电机制杀掉了代理进程。在安卓手机的“应用电池管理”中将该客户端设为“无限制/允许后台高耗电”，并在多任务后台界面给客户端加上“锁定”图标。
  - q: 排查完本地网络还是完全连不上，怎么区分是不是机场服务端出问题了？
    a: 用手机蜂窝移动网络（断开家里 Wi-Fi）测试同一组节点；如果手机流量正常而家宽全挂，是本地运营商或路由器问题；如果三网（电信/移动/联通）全挂且官网也无法登录、订阅返回空内容，再查阅官方公告或风险替代专题核实服务端状态。

# 机场网络故障排查与快速诊断中心

> **Answer-First 核心结论**：**遇到连不上、全部超时或网速骤降时，按“校对系统时间 → 查剩余流量与订阅是否更新 → 关掉冲突 VPN/加速器 → 切换手机流量交叉测试”这四步，可在 3 分钟内定位 90% 的问题属于本地环境还是机场服务端。** 请按下方“现象 → 根因 → 排查动作”表格直接定位你的故障专篇。

## 二、标准六步排障法（现象 → 原因 → 检查 → 处理 → 验证 → 下一步）

### 场景 A：所有节点瞬间全部超时（`Timeout`）
- **可能原因**：本地系统时钟不准（导致 VLESS/Trojan TLS 握手被服务器直接拒绝）、本地软件端口冲突、套餐到期或订阅过期。
- **检查与处理**：
  1. **校对时间**：打开系统时间设置点击“立即同步”，保证误差在 10 秒内。
  2. **检查 Clash/v2rayN 面板日志**：若日志大量出现 `tls: handshake failure` 或 `i/o timeout`，确认本地防火墙没有阻断内核（`verge-mihomo.exe` / `xray.exe`）。
  3. **更新订阅**：若机场刚迁移国内入口中转机，旧配置文件里全是死 IP，更新订阅后再测真连接延迟。
- **验证结果**：单选一个香港节点测试 `URL-Test`（非纯 TCPing），出现 20–80ms 数值且能打开测试页即恢复。

### 场景 B：订阅更新失败或返回 0 节点
- **可能原因**：直连拉取订阅域名被阻断、旧版客户端无法解析 VLESS-Reality/HY2 字段、或误买了仅支持专属端的品牌。
- **检查与处理**：
  1. 尝试在客户端勾选“通过代理更新订阅”，或电脑连手机 5G 热点拉取一次。
  2. 把订阅链接粘进无痕浏览器看是否能下载到文本内容（注意测试完立刻关闭，勿外传链接）。如果返回 `404/403`，登录官网重新生成“重置订阅”。
  3. 确认客户端内核：旧版 Clash for Windows 无法识别新协议节点，请换用 [Clash Verge Rev](/clients/clash-verge) 或 [v2rayN](/clients/v2rayn)。

### 场景 C：连接成功但网页转圈、速度极慢或延迟暴涨
- **可能原因**：DNS 污染、代理软件与浏览器扩展（如 SwitchyOmega）端口不一致、浏览器 QUIC 协议阻滞或本地晚高峰宽带限制。
- **检查与处理**：
  1. 检查客户端日志页（Logs）和连接页（Connections），看访问目标域名时究竟命中了 `DIRECT`、`PROXY` 还是报 `DNS resolve failed`。
  2. 在 Chrome/Edge 地址栏输入 `chrome://flags` 搜索 `QUIC` 并临时设为 `Disabled`，观察网页首屏加载是否立即提速。
  3. 交叉测试电脑与手机：若电脑慢而手机 5G 很快，说明是家用路由器 DNS、网线/Wi-Fi 或本地防火墙问题。

### 场景 D：本地网络问题 vs 机场服务端故障怎么区分？
| 测试表现 | 判定结论 | 下一步行动 |
|---|---|---|
| 手机 5G 正常，家里 Wi-Fi 全挂 | **本地宽带 / 路由器 / DNS 问题** | 重启光猫路由、更换本地 DNS 或改用手机热点 |
| 电脑某些端口超时，手机同一节点正常 | **电脑系统代理残留 / TUN / 杀软拦截** | 按 [Clash TUN 冲突](/diagnostics/clash-tun-conflict) 清理端口与驱动 |
| 电脑+手机三网全部超时，官网也打不开 | **机场入口维护或服务端异常** | 查看官方频道公告、等待维护窗口或核查 [跑路预警](/risks/exit-scam-warning) |

## 三、如何正确查看日志与向客服提供有效证据

如果排查后确认为服务端节点异常，联系客服前请先做好三项准备（能把沟通效率提高 5 倍）：
1. **截取客户端 Logs 面板的报错原文**（注意隐藏你的订阅 Token）；
2. **标明你的宽带运营商与省份**（例如“广东电信”或“河北联通”，三网出口路由不同）；
3. **注明具体失效节点名称与发生时段**（例如“香港专线 02 在 21:00 持续丢包，但新加坡 01 正常”）。

## 四、故障排查常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>为什么突然间所有节点在测速时全部显示 Timeout（超时）？</summary>

优先排查系统时间偏差、其他 VPN/加速器端口冲突以及机场变更入口后本地未更新订阅。

</details>

<details class="ad-faq-details">
<summary>节点测速有绿色延迟，但点开网页依然打不开怎么办？</summary>

多为 DNS 缓存污染或浏览器 DoH 绕过代理导致，刷新系统 DNS 缓存并关掉浏览器自定义安全 DNS 测试。

</details>

<details class="ad-faq-details">
<summary>点击“更新订阅”一直报 Network Error、403 或解析失败怎么处理？</summary>

切换手机热点或通过已有节点代理拉取订阅，同时核对客户端内核是否支持最新协议及机场是否开放通用订阅。

</details>

<details class="ad-faq-details">
<summary>关闭代理客户端之后，电脑连百度、微信都打不开了怎么恢复？</summary>

到系统网络设置手动关闭残留的“使用代理服务器”开关并重启浏览器清理 Fake-IP 缓存。

</details>

<details class="ad-faq-details">
<summary>开启 Clash Verge Rev 的 TUN 模式后反而全部断网是什么原因？</summary>

通常是未装 Service Mode 或与企业 VPN、网游加速器虚拟网卡驱动冲突。

</details>

<details class="ad-faq-details">
<summary>测速截图明明能跑 500Mbps，为什么我家 500M 宽带实际下载只有几 MB/s？</summary>

机房测速图多为 2G–9G 多线程非晚高峰快照，家宽晚高峰可能受本地路由器性能、QoS 或 QUIC 协议影响。

</details>

<details class="ad-faq-details">
<summary>手机锁屏一会代理就断开，必须重新点连接怎么办？</summary>

在手机系统电池管理中关闭对该客户端的后台省电限制并锁定多任务卡片。

</details>

<details class="ad-faq-details">
<summary>排查完本地网络还是完全连不上，怎么区分是不是机场服务端出问题了？</summary>

用手机 4G/5G 流量与家里宽带交叉测试；若多网全挂且官网无法访问，再去核实官方公告与备用方案。

</details>
