faq:
  - q: 关闭代理客户端之后电脑全网打不开任何网页怎么办？
    a: 这是最典型的“异常关闭导致系统代理残留 + Fake-IP DNS 缓存未清理”。当软件未正常点击“清除系统代理”就直接被杀进程或电脑重启时，Windows 系统设置里的“使用代理服务器 (127.0.0.1:7897)”还开着，浏览器傻傻往根本没人监听的端口发请求，当然全网断连；同时浏览器可能还缓存着刚才 Fake-IP 返回的 `198.18.x.x` 虚拟地址。解决办法是去系统“网络和 Internet → 代理”手动关掉“使用代理服务器”，并在终端运行 `ipconfig /flushdns` 清空缓存。
  - q: 为什么节点延迟只有 20–30ms，网页打开却极慢且长期“正在解析主机”？
    a: 首先要分清“测试环境与测试时段”的巨大鸿沟：例如资料库中 `2026-08-11` 与 `2026-08-19` 的多组测速图是在 **2Gbps–9Gbps 机房多线程高并发环境** 下跑出的节点极限峰值；而且 `2026-10-19` 汇总数据明确注为 **非晚高峰**。回到普通家庭 300M–1000M 宽带，受老旧光猫性能、2.4G Wi-Fi 穿墙、Chrome 单线程 HTTP3/QUIC 限速以及晚 21:00 全网抢带宽影响，体感跑分必然低一截。若晚间某区堵死，可手动试切负载均衡更轻的新加坡或日本节点。
  - q: 为什么在家看 YouTube/测网速比网站展示的 2Gbps/9Gbps 实测值低很多？
    a: Clash Verge Rev 开启 TUN 需要先在“设置”里安装并激活绿色盾牌/地球标记的 **服务模式 (Service Mode)**；如果安装失败，通常是被 360、火绒、腾讯电脑管家等安全软件拦截了虚拟网卡驱动注册。如果打开后完全无法解析 DNS，优先检查是不是同时开启了电脑自带“加密 DNS（DoH）”或系统内残留其他 VPN 的虚拟网卡（详见“TUN 冲突专项指南”）。
  - q: Clash Verge Rev 开启 TUN 模式失败怎么解决？
    a: 这是标准的本地 DNS 通道梗阻。重点排查两项：1）关闭 Chrome / Edge 浏览器设置里的“使用安全 DNS (DoH)”，避免浏览器直接往被干扰的外部加密服务器请求；2）检查你的客户端配置文件 `dns` 区块是否启用了高响应的 `Fake-IP` 模式，避免 `Redir-Host` 模式因为配置了响应极慢的上游海外 DNS 而拖死每一次页面点击。
  - q: 看视频总转圈，禁用 Chrome 的 QUIC 协议真的有用吗？
    a: 现代 YouTube、Google 默认会优先使用基于 UDP 传输的 HTTP/3（QUIC）协议来加载视频流。部分机场的某几个中转入口节点或您本地移动/铁通宽带会对持续大流量 UDP 包进行极其严格的运营商 QoS 丢包限速！此时只要在 Chrome 地址栏输入 `chrome://flags`，搜索 `Experimental QUIC protocol` 并设为 `Disabled`（禁用）重启浏览器，强制降级回更稳的 TCP TLS 通道，视频加载速度往往立刻起飞。

# 代理 DNS 错误、TUN 模式异常与网络速度慢排查指南

**“延迟测试明明才二三十毫秒，网页却始终转圈显示正在解析主机”、“软件明明退出关掉了，电脑反而连百度也打不开了”、“为什么实测图能跑五百兆，我家里才跑几十兆？”——这三类让人抓狂的疑难，95% 都集中在系统代理残留、DNS 解析路径打架、浏览器 QUIC 协议受限以及机房 vs 家宽环境偏差这四个具体环节。**

---

## 一、DNS 与 TUN 异常排错矩阵（现象 → 检查 → 处理）

| 故障现象 | 根本技术原因 | 检查点与自救动作 | 验证通过标准 |
|---|---|---|---|
| **关闭客户端后，全电脑连国内网页也打不开** | 异常退出未清除 Windows/macOS 系统代理设置，或系统残存 `198.18.x.x` Fake-IP DNS 缓存 | 1. 打开系统“网络和 Internet → 代理”，关闭“使用代理服务器”<br>2. 在 Windows CMD 运行 `ipconfig /flushdns`（Mac 运行 `sudo dscacheutil -flushcache`）并重启浏览器 | 关闭客户端后，百度/淘宝/B站立刻秒开，且查询本机 IP 为真实当地宽带 IP |
| **挂着代理，浏览器左下角长期卡在“正在解析主机”** | 浏览器自带 DoH（安全 DNS）绕过代理抢跑；或配置里用慢速海外 DNS 阻塞了国内域名 | 进入 Chrome/Edge“隐私与安全”设置，**关闭“使用安全 DNS”**；确保客户端工作在正常的 `Fake-IP` 模式且规则正常加载 | 输入海外新网址后无需卡顿 5–10 秒，瞬间完成首字节解析加载 |
| **Clash Verge Rev 开启 TUN 失败或报错没有权限** | 未安装系统后台 Service Mode，或被 360/火绒拦截虚拟网卡 `wintun` | 在 Clash Verge Rev 设置里点击“服务模式”授权安装并彻底重启软件；确认安装包来自官方源后加入安全软件信任区 | 设置栏服务模式亮起绿色标记，TUN 开关可顺畅点亮开启 |
| **打开 TUN 反而微信正常、谷歌失联或反之** | 存在多个 TUN/VPN 驱动冲突、或者路由表未清干净 | 退出所有企业 VPN、游戏加速器及虚拟机冲突网卡；参见 [TUN 冲突专项排查](/diagnostics/clash-tun-conflict) | 在终端输入 `curl -I https://www.google.com` 秒返回 `200 OK` |

## 二、为什么实际下载速度远低于网站展示的实测图？

当您在 [测速数据库](/database/speedtests) 里看到某品牌峰值高达 400–500 Mbps（甚至 9Gbps 机房测出单线程 300+MB/s），而自己家里却觉得没有跑那么快，请务必从以下 **5 个真实变量** 逐一排查（不要盲目下结论认为品牌数据造假，也不要无依据盲信极限峰值）：

### 1. 客观区分测试基础设施差异
- **多 Gbps 数据中心专线机房测试环境 vs 家庭终端网络**：资料库中的 `2026-08-11` 与 `2026-08-19` 测速记录，多是在 **2Gbps–9Gbps 商业服务器环境** 以多线程测出的节点带宽吞吐上限；而普通家庭宽带上限本身只有 300M/500M/1000M，中间还经过墙内老旧百兆网线、5GHz/2.4G Wi-Fi 无线衰耗及低功耗家用光猫转发，末端实测能跑到自家宽带的一半至七成已属优质。

### 2. 晚高峰（20:30–23:00）与非晚高峰的必然回落
- 本站 `2026-10-19` 全库横向汇总已如实注明测速采集于 **非晚高峰时段**。晚上 9 点是全网家庭宽带同时刷 4K、打联机和下大文件的并发最高峰，不管是骨干网出国路由还是机场共用中转入口都会经历带宽摊薄。
- **自救验证技巧**：晚上卡顿时，不要全网死守人数最拥挤的“香港 01/02”，主动切换同机场的**新加坡节点或日本节点**（有时甚至同区编号靠后的 05–10 号节点）测一测，往往速度立竿见影翻倍。

### 3. 移动/铁通等宽带对 UDP（QUIC / HTTP3）的隐形限速
- **极其高发的提速神操作**：Chrome、Edge 与 YouTube 客户端默认启用 **QUIC (HTTP/3)**（基于 UDP 协议传输视频）。国内部分省市的家庭宽带（尤其是部分移动宽带与长城/广电等二三级宽带）对突发大流量 UDP 包有极严的 QoS 限速阈值，导致网页能开但看视频死活缓冲转圈！
- **验证方法**：在 Chrome 地址栏输入 `chrome://flags`，在搜索框查 **`Experimental QUIC protocol`**，将 `Default` 改成 **`Disabled`**，点击右下角 `Relaunch` 重启浏览器，再看 4K YouTube 缓冲条拉满速度，常有奇效。

### 4. 检查本机测速软件与协议客户端硬件瓶颈
- 老旧电脑、极低端路由器（如百元硬路由跑 AES-256 或复杂规则）在拉满上百兆加密解密流量时，CPU 单核占用可能早就顶到 100% 了，成为“真正卡死网速的木桶短板”。测试节点极速时，打开任务管理器确认本地 CPU 没有因加解密跑满。

## 三、信息边界与诚实披露

- **单线程体验 vs 多线程测速面板**：部分测速软件展示的是“16 线程并发下载总和”，对于网页浏览与单文件下载，真正的决定因素是“单线程延迟与单连接持续吞吐（Single Thread）”。选购机场并测试速度时，用真实打开 4K 视频加载缓冲速度或下载一个海外大文件，比单纯盯着测速仪跑出来的极速峰值数字更有实用参考价值。

## 四、常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>关闭代理客户端之后电脑全网打不开任何网页怎么办？</summary>

说明客户端异常退出没有自动清除系统代理设置，或系统 DNS 缓存着未刷新的 `198.18.x.x` 虚拟 IP。进入 Windows/Mac 网络设置关闭“使用代理服务器”，在命令行执行 `ipconfig /flushdns`（Windows）并重启浏览器即可秒恢复。

</details>

<details class="ad-faq-details">
<summary>为什么节点延迟只有 20–30ms，网页打开却极慢且长期“正在解析主机”？</summary>

多为浏览器内置“安全 DNS (DoH)”绕过代理导致解析打架。关闭 Chrome/Edge 设置中的“使用安全 DNS”，并确认代理配置使用了流畅的 `Fake-IP` DNS 方案。

</details>

<details class="ad-faq-details">
<summary>为什么在家看 YouTube/测网速比网站展示的 2Gbps/9Gbps 实测值低很多？</summary>

机房实测环境代表服务器线路上限，且 `2026-10-19` 汇总数据为非晚高峰样本；家庭侧受家宽上限、Wi-Fi 损耗、运营商针对 UDP/单线程的 QoS 限制及晚高峰并发竞争影响，不可直接按机房极限对标。建议对比晚间实际播放 4K 流畅度并尝试关闭 Chrome 实验性 QUIC 协议。

</details>

<details class="ad-faq-details">
<summary>Clash Verge Rev 开启 TUN 模式失败怎么解决？</summary>

必须在软件“设置”里安装授权服务模式（Service Mode）并重启；若安装提示报错或被屏蔽，检查电脑安全软件（360/火绒/Defender）的防护拦截记录，确认官方源后放行虚拟网卡驱动。

</details>

<details class="ad-faq-details">
<summary>看视频总转圈，禁用 Chrome 的 QUIC 协议真的有用吗？</summary>

对于移动等对大流量 UDP 包存在隐形限速的运营商宽带、或者部分仅面向 TCP 做了极致优化的中转机场，在 `chrome://flags` 关闭 `Experimental QUIC protocol` 强制浏览器走稳定 TCP TLS 往往能带来极其明显的缓冲提速。

</details>
