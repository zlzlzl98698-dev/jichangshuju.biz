faq:
  - q: 节点还能连上外网，为什么点“更新订阅”就报 Fetch failed？
    a: 这是最常见的情况：你的机场“节点线路”本身没坏，但机场用来给你下发最新订阅列表的“API 网址域名”被本地运营商 DNS 污染拦截了，导致客户端在直连状态下够不着它。解决办法极其简单：在 Clash Verge Rev 里右键你的订阅卡片，勾选设置里的“通过代理更新（Use Proxy）”，让它借着目前还能用的旧节点绕道拉取新订阅；或者在 v2rayN 里点“更新全部订阅（通过当前代理）”。
  - q: 刚买的新机场还连不上网，直连导入提示 Network Error 怎么办？
    a: 四种最快无痛绕过法：1）把手机切换成 4G/5G 移动流量开热点给电脑连，或者手机直接用蜂窝流量更新小火箭（家庭宽带光猫和手机移动运营商对同一域名的污染策略常有不同）；2）登录机场官网控制台看看有没有提供“备用订阅域名”开关；3）直接用浏览器打开订阅网址把返回的配置文件保存成 `.yaml` 文件手动拖入客户端本地导入；4）确认是不是把复制链接时前后带的中文文字或换行一起贴进去了。
  - q: 导入成功但显示 0 个节点或 YAML 格式错误是什么原因？
    a: 检查是否把“V2Ray 通用 Base64 链接”硬塞进了只吃 Clash YAML 格式的入口，或者相反——把 Clash 配置文件链接塞给了仅支持 Base64 订阅的老旧 V2Ray 菜单！去机场官网仪表盘准确对应按钮：“Clash 客户端”点专用 Clash 导入按钮；“v2rayN/v2rayNG”复制标准通用/V2Ray 订阅；另外部分老官网后台在链接末尾加 `&flag=clash` 才能输出正确格式。
  - q: 更新订阅突然返回 403 或 401 是怎么回事？
    a: 返回 `403` / `401` 代表订阅服务器端明确拒绝了本次身份认证或请求标识。最常见三个原因：1）你在官网控制台点过“重置订阅链接”，手里那条旧地址已经作废；2）你的机场账户因为疑似多人群发共享、违背条款或套餐已过期欠费被停用；3）机场防火墙（如 Cloudflare WAF）拦截了某些特定版本客户端自带的异常 `User-Agent` 请求头（Clash Verge Rev 中可在订阅设置修改 UA 为 `ClashforWindows` 或 `clash-verge` 测试）。
  - q: 进机场官网后台死活找不到任何订阅链接在哪复制怎么办？
    a: 不一定是买错了，很可能是你选购了“纯品牌官方自研专属客户端”路线的机场！例如本站品牌库里的飞猫云、SOGO 云、隐形人以及近期采用专属策略的 Firefly/无忧链接/灵猫网络，官方出于管控或降低新手门槛考量，故意完全关闭了第三方 Clash/小火箭通用订阅接口。此类服务无法用 Clash/v2rayN 导入，直接去官网下载他们自家的电脑或手机官方 App 登录账号密码即可使用。

# 机场订阅更新失败与无法连接怎么解决？（403 / Network Error / 解析报错）

**遇到客户端点击更新订阅弹出 `Network Error`、`Fetch failed`、`YAML 解析错误` 或 `403 Forbidden` 时，别反复点击重试甚至把配置删了导致彻底丢掉还能用的旧节点——绝大多数订阅故障，根源只落在“直连 API 域名被本地干扰”、“选错了订阅格式”或者“该品牌根本仅支持官方专属端”三件事上。**

---

## 一、常见报错码与故障现象精准对照表

| 客户端弹窗提示 / 现象 | 精准原因归因 | 快速处理方案 |
|---|---|---|
| **`Fetch failed` / `Timeout` / 连接重置**<br>（但旧节点其实还能翻墙） | 下发订阅列表的机场后端域名被本地宽带直连屏蔽，客户端不走代理直连拉取时被拦截 | 右键订阅打开 **“通过代理更新（Use Proxy）”**（v2rayN 选“通过当前代理更新”），借用能通的旧节点去拉新列表 |
| **首次全新导入就报 `Network Error` / 超时** | 本地家用宽带拦截了机场订阅域；或复制订阅 URL 时前后带上了换行符、空格、汉字说明 | 1. 核查文本头尾无多余空格汉字<br>2. **切换手机 4G/5G 热点重试**<br>3. 去机场官网找“备用订阅地址”或直接下载本地文件拖入 |
| **`YAML Parse Error` / 节点数量显示 `0`** | **格式张冠李戴**（如把 Base64 节点串塞给 Clash）；或复制了受微信/QQ 浏览器转码截断的残缺网址 | 回到官网仪表盘严格区分点击 **“Clash 专用链接”** vs **“V2Ray 通用链接”**；切忌经微信文件传输助手转发被加转义符 |
| **`403 Forbidden` / `401 Unauthorized`** | 旧订阅 Token 已被重置作废、套餐已彻底到期、或者 Cloudflare 防火墙误杀了客户端默认的 `User-Agent` 请求头 | 1. 登录官网核实账号状态并重新复制最新订阅 URL<br>2. 在订阅右键设置中把 `User-Agent` 改填 `clash-verge` 或 `Clash` 试探通过防火墙 |
| **官网后台完全找不到任何订阅链接与一键导入按钮** | 所购品牌走的是 **纯专属客户端路线**（不向用户开放通用 Clash/小火箭配置） | 确认品牌类型（如飞猫云、SOGO 云、隐形人等），**放弃导入第三方端**，改下官网提供的品牌官方客户端账号密码登录 |

## 二、标准五步排查执行顺序（稳妥不失联）

### 第 1 步：先别删除现有的“能用旧配置”
很多新手一看到“更新失败”，第一反应就是把软件里的配置右键“Delete 删掉再重导”——如果此时恰好机场官网订阅接口正遇短时维护，删掉之后你就连手头上唯一还能连网查客服的旧节点也没了！**务必先尝试就地刷新或新增一条测试。**

### 第 2 步：核查“是不是纯专属客户端品牌”
在本站收录的 31 个品牌中，两大技术阵营截然不同（参见 [客户端兼容性全表](/database/clients)）：
- **开放第三方通用订阅**：如 [光速云](/brands/guangsuyun)、[星岛梦](/brands/xingdaomeng)、[暮光加速](/brands/muguang)、[一翻云](/brands/yifan)、[二猫云](/brands/ermao)、[梯子云](/brands/tiziyun) 等，一定能找到复制链接入口；
- **纯官方专属端**：如 [飞猫云](/brands/feimao)、[SOGO 云](/brands/sogo)、[隐形人](/brands/yinxingren) 等不提供订阅链接，直接去品牌官网下载独立客户端即可。

### 第 3 步：检查订阅字符串本身有没有被污染或截断
- **严禁通过微信/QQ 手机端互传链接后再复制**：微信和某些国产输入法可能会自动把链接里的 `&` 转义成 `&amp;` 或者在末尾自动补个回车或多余参数，一旦破坏掉 URL 的 `token=` 秘钥就会立刻报错 `401`/`403` 或解析空白！
- **检查完整头部**：标准链接均以 `https://`（少数以 `http://`）开头，中间不带任何中文汉字和空格。

### 第 4 步：绕过直连网络封锁（借道更新与离线导入双绝招）
如果链接 100% 正确但依然超时：
- **招数 A（开手机热点）**：电脑连手机 4G/5G 热点直连更新订阅，往往家用光纤拦截的域名在手机蜂窝网络下能顺畅放行；
- **招数 B（借当前代理刷新）**：在 Clash Verge Rev 订阅设置里勾选 **`通过代理更新 (Use Proxy)`**（需确保系统当前已连着有效代理），绕过运营商直接去机场服务器取新列表；
- **招数 C（本地文件拖入兜底）**：当你挂着备用梯子或者手机能在浏览器直接打开那条订阅地址时，界面会直接显示或下载出一整个 `.yaml` 文件。把它保存到桌面，直接用鼠标**把 `.yaml` 文件拖进 Clash Verge Rev 的“订阅”页面里**，同样能本地加载成功（记得后续恢复网络后再切回在线 URL 方便同步更新）。

### 第 5 步：如果提示流量异常或链接泄露，立即重置订阅地址
若后台出现莫名被消耗几十 GB 流量或持续报错 `403`，第一时间进入机场控制台点击 **“重置订阅链接 (Reset Subscription)”** 作废旧 Token，再把全新生成的新地址重新导入你自己的各个设备。

## 三、信息边界与诚实披露

- **面板端系统临时故障**：极少数时候并不是您的设备或网络问题，而是机场后台面板自身数据库崩溃、Cloudflare SSL 证书过期或机场主关闭了免费域名中继导致的 502/522 报错。若换用 4G 流量及浏览器直接打开官网也出现 502/连接超时，属于服务端维护，请耐心关注官方通知渠道或工单提示。

## 四、常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>节点还能连上外网，为什么点“更新订阅”就报 Fetch failed？</summary>

因为拉取订阅文件的官网 API 域名在直连环境下被局部屏蔽了。只需在客户端右键订阅开启“通过代理更新（Use Proxy）”，让客户端走现有节点通道去拉取最新名单即可完美解决。

</details>

<details class="ad-faq-details">
<summary>刚买的新机场还连不上网，直连导入提示 Network Error 怎么办？</summary>

先检查复制链接前后有没有带多余空格或汉字，再尝试把电脑切到手机 4G/5G 热点刷新；或者查询机场官方提供的最新备用订阅域名，也可以先把配置文件用浏览器下载下来直接本地拖入软件使用。

</details>

<details class="ad-faq-details">
<summary>导入成功但显示 0 个节点或 YAML 格式错误是什么原因？</summary>

最常见原因是把“V2Ray Base64 通用链接”粘贴进了“Clash”格式导入框，或者反之。请回到机场后台按您使用的软件名称精确复制对应的订阅链接格式。

</details>

<details class="ad-faq-details">
<summary>更新订阅突然返回 403 或 401 是怎么回事？</summary>

通常是因为您在官网手动“重置”过订阅地址导致手里那条链接过期、套餐已经耗尽停服、或者机场安全防火墙误拦截了老旧客户端的 User-Agent 标识（可尝试在订阅高级设置修改 UA 重试）。

</details>

<details class="ad-faq-details">
<summary>进机场官网后台死活找不到任何订阅链接在哪复制怎么办？</summary>

请核对您购买的是不是仅支持自研专属 App 的品牌（如飞猫云、SOGO 云、隐形人等）。纯专属架构没有外部订阅地址，直接下载官方对应系统的 App 输入注册账密登录使用即可。

</details>
