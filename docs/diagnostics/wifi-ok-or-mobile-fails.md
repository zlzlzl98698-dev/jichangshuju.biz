faq:
  - q: 为什么家里 Wi-Fi 节点全 Timeout，切手机 4G 流量瞬间全部绿色畅通？
    a: 这是极其常见且**立刻可以排除“机场跑路”**的信号！它证明机场的服务器100%健康活着，毛病精准出在你家宽带到机房这一段：主要原因包括：1）**家庭宽带光猫或路由器开启了原生 IPv6**，系统优先走未经代理的直连 IPv6 撞墙卡死；2）**宽带运营商与移动运营商的局部 DNS 拦截不同**（如家里电信光猫劫持封掉了机场的旧订阅域，而手机联通 5G 还没拦）；3）**某些老旧家用路由开启了严苛防火墙/省流节能或 MTU 异常**。
  - q: 反过来，家里 Wi-Fi 好用但出门用手机 5G 连不上怎么处理？
    a: 移动蜂窝网络环境（尤其中国移动 4G/5G 基站及部分地区校园基站）与有线宽带区别极大：1）很多移动端基站对**持续大流量 UDP 包（例如基于 QUIC 的 Hysteria 2 协议、或者 YouTube HTTP/3）** 施加极其严苛的 QOS 限速丢包甚至端口切断，切回标准 TCP 传输协议节点常可瞬间恢复；2）移动基站切换时 IP 频繁变更且手机开启了系统“省电模式/限制后台流量”；3）部分老旧或偏远机场针对手机 5G 的专属中转入口支持不如常规电信/联通稳健。
  - q: 大学宿舍校园网与公司内网环境下选什么端口和协议最容易通过？
    a: 绝大多数大企业办公网与高校校园网部署了**企业级应用防火墙（DPI）与非标端口白名单**——不仅屏蔽了大多数非 80/443 的冷门端口（例如某些机场自设的 `23456`、`50000` 端口全部被校园网关无声丢弃），还会主动拦截外部个人代理客户端的握手特征包。在校园网环境自查时：优先试着切换订阅里端口为 **`443`（HTTPS 标准加密口）的节点**（如基于 TCP TLS 的 Trojan / VLESS-Reality 443 节点），避开乱七八糟的高位端口与易被一刀切的纯 UDP 端口。
  - q: 关闭家里的“IPv6”真的能解决很多奇怪的连接转圈吗？
    a: 现在国内光猫几乎全默认下发了公网 IPv6。当你的手机或电脑同时拥有 IPv4 与 IPv6、而你代理客户端/软路由并没有完美做好 IPv6 接管转发时，系统网络栈经常遵守 `IPv6 优先于 IPv4 (Happy Eyeballs)` 原则直接发直连包撞向海外 IPv6 地址，导致打开国外网页卡转圈十几秒。排查方法极其直观：在客户端软件设置中先临时关闭 `IPv6` 选项（或在路由器后台临时停用 LAN 口 IPv6 分配），如果瞬间起飞，就实锤是 IPv6 抢跑惹的祸。
  - q: 为什么有的机场在我家电信宽带飞快，用移动手机卡就很慢？
    a: 这是地方宽带运营商 DNS 抢答或光猫自带“安全防护插件”在作祟。进系统或路由器把本地宽带上游 DNS 改填纯净公共 DNS（如 `223.5.5.5` / `119.29.29.29`），同时在光猫管理页关掉冗余的“网址安全过滤/儿童保护屏蔽”功能，并在软件里开启“通过代理更新订阅”绕开直连污染。

# Wi-Fi 无法连接但手机移动网络可以（或反之）怎么排查？跨网络环境诊断手册

**发现同一部手机、同一款软件、甚至同一秒钟内的同一个机场账号，在“连接家里/公司 Wi-Fi”时一排节点全红 `Timeout`，但只要手指往下滑关闭 Wi-Fi 改走“手机 4G/5G 蜂窝网络”瞬间全绿秒开——或者恰好完全反过来！这种看似灵异的现象其实是排除机场停摆的最快试金石，精准指向了不同基础接入网（宽带光猫、校园/企业网关、移动基站、IPv6 与 UDP 策略）之间的底层规则碰撞。**

---

## 一、两大经典对称故障交叉排查矩阵

| 现场对比症状 | 几乎可以 100% 排除的问题 | 真正出问题的三大嫌疑环节 |
|---|---|---|
| **Wi-Fi 全挂 / 卡顿 ❌<br>手机 4G/5G 移动流量全绿秒开 ✅** | 机场没跑路、套餐没到期、客户端配置和系统时间大概率完全正常 | 1. **家庭路由器/光猫启用了原生 IPv6 抢跑撞墙**<br>2. **家用宽带（或公司/校园网关）封堵了该机场的订阅域名或非 443 端口**<br>3. 光猫固件死机、地方宽带特定时段国际或中转路由故障 |
| **家里宽带 Wi-Fi 流畅 ✅<br>手机 4G/5G 蜂窝网连不上 / 断流 ❌** | 账号正常、配置导入基本无误 | 1. **移动蜂窝基站屏蔽或严格限速 UDP 流量（如 Hysteria 2 节点 / QUIC）**<br>2. 手机系统对“蜂窝网络数据权限”未授权给代理核心或省电策略在 5G 切网时强杀后台<br>3. 该机场中转入口对您使用的手机所属运营商（尤其是某些省市移动/广电卡）路由极差 |

---

## 二、情景 A 修复实战：Wi-Fi 连不上，一开手机流量就好了

遇到这个场景，请按由简到繁 4 步精准排雷：

### 1. 第一步：5 秒验证并拦截“IPv6 双栈抢跑”
国内三大运营商家庭宽带如今几乎全默认推送双栈原生 IPv6。如果你的系统同时拿到了原生 IPv6，但本地客户端或家庭路由器没有配置全套 IPv6 隧道转发规则，打开网页和软件就会抢先走未经代理保护的直连 IPv6 通道撞墙！
- **排查处理**：
  - 打开代理客户端设置（例如 Clash Verge Rev 设置或覆写 YAML），先将 **`ipv6: false`** 关闭测试；
  - 在家用路由器管理界面（一般 `192.168.1.1` / `192.168.31.1`）关闭“IPv6 设置”里的 LAN 口通告重试对比，常能在一秒内立竿见影消掉卡顿和超时！

### 2. 第二步：排查“学校宿舍校园网 / 公司企业 Wi-Fi 防火墙封杀”
企业 IT 网关和高校锐捷/深信服认证网经常配置极严厉的策略：**直接无声丢弃所有非 HTTP(80)/HTTPS(443) 的冷门高端口通信，且高强度识别拦截 UDP 隧道！**
- **针对性避让方案**：
  - 优先在你的节点列表里挑**端口为 `443`、且协议基于标准 TCP TLS 伪装**的节点（如 `VLESS-Reality:443` 或 `Trojan:443`），避开类似 `:24580`、`:51234` 这种五位数野端口；
  - 暂时关闭基于 UDP 的 Hysteria 2 节点，改选纯 TCP 专线节点；
  - 若仅仅是点“更新订阅”失败，先开手机 4G 热点把订阅更新到手机/电脑本地，再切回校园网尝试连节点本身；
  - 确保已通过校园网浏览器弹出的 Web 登录验证（如果还没点认证过校园网，所有包都会被校园网关劫持，导致节点全红）。

### 3. 第三步：修复光猫 / 家用宽带运营商 DNS 拦截
如果连带着官网本身打不开或每次刷新订阅直接报超时：
- 不要使用“宽带自动获取的本地运营商 DNS”（部分光猫内置所谓“反诈中心拦截过滤”或运营商局部屏蔽会把机场 API 域直接返回假地址）；
- 在电脑网络适配器或路由器上游 DNS 改为纯净国内公共 DNS（如 `223.5.5.5` 与 `119.29.29.29`），重插或重启一次用了几个月没歇过的光猫路由器清掉拥塞 NAT 会话表，再用客户端勾选“通过代理更新”。

## 三、情景 B 修复实战：家里 Wi-Fi 稳如狗，出门切手机流量就残废

遇到这种移动端外出断网现象，重点检查以下三点：

1. **换掉纯 UDP 协议节点与关闭 QUIC**
   如果你买到了提供 **Hysteria 2** 或开启高并发 UDP 的节点，在移动基站上行波动或遇到运营商对 UDP 包严苛限速的省市里，在家里 Wi-Fi 下能跑满，出门 5G 可能寸步难行。**在户外用手机流量时，首选切换到基于 TCP 传输的 IEPL 专线、Shadowsocks 或 Trojan/VLESS 节点**，并尽量使用 Chrome/App 内标准 TCP 连接模式。
2. **检查手机“系统联网权限”是否错把蜂窝流量禁了**
   在 Android 与 iOS 的“设置 → 移动网络/应用联网权限”中，确认不仅允许你的客户端软件“使用 WLAN”，也要打勾允许其 **“使用移动数据（WLAN 与蜂窝网络）”**——尤其注意新安装某些开源工具或系统更新后可能默认没放开后台数据同步权限。
3. **测试“同机场的不同入口与三网路由适配差异”**
   就像在本站 [光速云 `2026-08-19` 三网 MiaoKo 实测](/brands/guangsuyun) 中能清晰看到的事实：**同一个节点对电信、联通和移动三网延迟差异非常明显**！家里拉的是中国电信宽带、而手里手机卡插的是中国移动或广电卡时，本质上是在使用两家完全不同的基础网络接入同一家机场。如果家里电信好而外出移动卡炸，试试勾选机场列表里专门标注着 `移动优化` / `三网 BGP` 或不同城市入口（例如从上海入口换成广深入口）的备用节点对比测试！

## 四、信息边界与诚实披露

- **非物理层基站盲区提醒**：在地铁车厢、电梯间、地下车库或高铁高速切换基站过程中出现的短时断流，属于物理无线信号切换造成的 TCP 连接重置，更换任何机场的节点均无法违背射频通信物理极限；此时在客户端打开“切换网络时重置连接”或快速手动重开关一次主开关更为有效。

## 五、常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>为什么家里 Wi-Fi 节点全 Timeout，切手机 4G 流量瞬间全部绿色畅通？</summary>

这首先证明机场服务完全正常没跑路！90% 原因是：家里路由器/光猫启用了 IPv6 引发客户端抢跑撞墙、光猫/地方宽带局部 DNS 拦截了入口域名、或者您在公司/校园网环境受到内部防火墙端口管控限制。

</details>

<details class="ad-faq-details">
<summary>反过来，家里 Wi-Fi 好用但出门用手机 5G 连不上怎么处理？</summary>

重点检查三项：1）避开部分手机蜂窝网络极易限速拦截的纯 UDP 节点（如 Hysteria 2），改用标准 TCP 协议节点；2）在手机设置核实已为该代理软件开启“WLAN 与蜂窝网络”联网权限；3）测试更换同一机场不同入口地区（比如广深口换沪日口）匹配手机卡所属运营商（如移动/联通/电信）。

</details>

<details class="ad-faq-details">
<summary>大学宿舍校园网与公司内网环境下选什么端口和协议最容易通过？</summary>

校园网和企业网通常仅严密放行常见 Web 端口。尽量挑订阅中端口为 **`443`** 且伪装成普通 HTTPS 流量的节点（如 VLESS-Reality 443 或 Trojan 443），避开五位冷门高位端口与纯 UDP 通道，并先用手机热点更新订阅。

</details>

<details class="ad-faq-details">
<summary>关闭家里的“IPv6”真的能解决很多奇怪的连接转圈吗？</summary>

是的。当本地网络分配原生 IPv6 地址但代理工具与路由器缺乏完善的 IPv6 透明分流规则时，系统优先发出直连 IPv6 导致大量海外请求卡死超时。测试期先把客户端与路由器的 IPv6 功能暂关，即可一秒验证。

</details>

<details class="ad-faq-details">
<summary>为什么有的机场在我家电信宽带飞快，用移动手机卡就很慢？</summary>

国内电信、移动、联通三家运营商的跨境海缆及对接国内机房 BGP 路由天生不同（正如本站三网实测图中长沙电信、广西移动与河北联通各自的曲折差异）。选购时务必在最常用的主网络环境下用首月月付实测验机。

</details>
