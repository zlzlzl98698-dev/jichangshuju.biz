# 机场套餐数据库与流量成本计算器

> **Answer-First 核心结论**：周期套餐与不限时套餐必须分开比较：周期套餐的平均月成本为 `实付金额 ÷ 计费月数`，标称每 GB 成本为 `平均月成本 ÷ 每月标称流量`；不限时套餐不折算固定月成本，其单位成本为 `一次性付款 ÷ 总流量`。

## 计算公式与估算边界

1. **倍率修正**：若节点存在 `2x` 或 `3x` 流量倍率，实际可消耗有效流量 = `标称流量 ÷ 平均倍率`，单位真实成本会成倍上升。
2. **折扣叠加限制**：光速云明确规定轻量版与 147 永久套餐不参与折扣；Firefly 与闪跃的 8 折码同样不适用于年付版。切勿将折扣率默认套用到入门年付档。
