# AI 与流媒体可用性矩阵（Service Availability Matrix）

**AI 工具与流媒体解锁高度依赖具体落地 IP 与平台风控规则，绝不能将品牌宣传口号直接视作全节点永久可用。** 本矩阵将“实测证据（如光速云 2026-08-19 MiaoKo 实测、灵动云 2026-07 60 解锁样本）”与“品牌方资料声明”严格分开展示。

## 关键发现摘要

1. **光速云（具备节点级实测截图）**：2026-08-19 MiaoKo 实测显示，香港专线对 Netflix / Disney+ 解锁稳定，但 OpenAI 多提示“仅APP(HK)”，Gemini 多在新加坡节点成功解锁；70 节点 VLESS 批次中日本/美国/新加坡节点 OpenAI 广泛解锁，台湾/新加坡部分节点 YouTube 曾出现送中(CN)。
2. **灵动云（具备 60 节点解锁样本摘要）**：2026-07-20/21 实测显示 OpenAI 各地区基本全解锁，但 TikTok 多失败、新加坡与台湾 YouTube 送中、台湾落地 Netflix/Disney+ 识别为西班牙(ES)。
3. **可信云（高透明度声明）**：品牌资料主动说明“AI 与流媒体缺乏统一实测数据”，不做夸大承诺。
4. **速界（AI 场景定位与风控提醒）**：重点强调 ChatGPT / Claude / Gemini，同时主动声明受 IP、地区与风控政策影响，不保证永久稳定。
