  - q: 小火箭开启后状态栏 VPN 图标一闪而过就自动关闭怎么修？

  - q: 用了小火箭之后国内淘宝、微信和网银变卡还狂耗机场流量是什么原因？
    a: 千万不能把小火箭的“全局路由”留在“代理（Proxy）”！日常必须锁定为 **“配置（Config）”** 模式，同时在底部“配置”页确保选中的是一份包含了完整大陆直连规则（GEOIP,CN,DIRECT）的活动配置文件，才能保证国内软件全速不扣流、海外软件精准走节点。
  - q: 为什么我借的旧版小火箭导不进机场链接或者新节点显示不支持？
    a: 请花 10 秒核实一下该机场是不是**“仅支持品牌专属 App”**！例如飞猫云、隐形人、SOGO 云以及 2026-10 之后的无忧链接、Firefly 等不提供标准通用订阅链接，只允许下载他们自家做的专用 iOS 包。如果是这类服务，Shadowrocket 再怎么折腾都是导不进去的。

# iPhone 小火箭 Shadowrocket 连接不上与后台闪断怎么排查？（6 步解决）

**在 iPhone 与 iPad 上，[Shadowrocket（小火箭）](/clients/shadowrocket) 出现连不上网、测速全红 `Timeout` 或者锁屏一会“VPN 图标自动消失”，绝大多数情况并不是软件买错了或苹果系统封杀，而是卡在了“iOS 50MB 插件内存红线闪退”、“订阅未同步更新”、“iCloud 专用代理冲突”或“系统时间与路由配置错位”这几个移动端独有的机制上。**

---

## 一、快速症状定位：你的小火箭属于哪一类故障？

| 屏幕直观表现 | 最核心底层归因 | 立即执行的修复动作 |
|---|---|---|
| **顶部 `VPN` 标志亮起 2–5 秒后立刻自动熄灭** | **触发 iOS 50MB 内存硬限制被系统强杀（OOM）**；或同时开着另一款 VPN 描述文件抢夺通道 | 转跳步骤 1（删减超大规则集、停用冗余模块与本地日志） |
| **测速“连通性测试”全红 `Timeout`（无一绿字）** | 机场修改入口后旧订阅未更新、手机时间误差过大、套餐到期或节点与过时配置不匹配 | 转跳步骤 2–3（校准系统自动时间 + 蜂窝网刷新订阅） |
| **有绿色延迟数值，但打不开谷歌或国内微信突然转圈** | 全局路由错设成了 `Proxy` / `Direct`、开启了 Apple iCloud 专用代理、或网络接口缓存僵死 | 转跳步骤 4–5（恢复 `Config` 模式 + 关闭 Private Relay） |
| **找不到机场订阅地址 / 扫进去显示格式不支持** | 误买了“仅限品牌官方自研软件”的机场（无通用订阅） | 转跳步骤 6（核验品牌客户端兼容性） |

## 二、6 步无损排错实战流程（从简到繁）

### 第 1 步：解决“VPN 开关刚打开就自动弹出关闭 / 看一会儿闪断”
苹果 iOS 对运行在后台的 `NEPacketTunnelProvider` 网络扩展组件执行铁血内存封顶：**约 50MB 物理内存红线**，只要超过一丁点系统瞬间强杀进程，绝不宽容！
- **排查处理**：
  1. 点进小火箭底部第二个标签 **“配置 (Config)”**，确认你当前使用的不是某个动辄三五万行（包含了全量广告屏蔽列表 + 全量历史站点清单 + 重写 JS 脚本）的“巨无霸豪华配置”。
  2. 立即切回**精简干净的默认白名单分流配置**（仅包含基础 `FINAL,PROXY` 与标准 `GEOIP,CN` 规则，文件体积通常小于 500KB）。
  3. 点开底部“设置”确认未开启消耗大量内存的全量调试抓包日志，随后长按重启一次代理连接测试是否稳住不掉。

### 第 2 步：强制校验手机系统时间与时区（极隐蔽的握手杀手）
- 打开 iPhone **“设置 → 通用 → 日期与时间”**，务必开启 **“自动设置”**。
- 如果您因为某些海外 App 或游戏习惯把手机手动拨快/拨慢过几分钟、甚至切错夏令时区，VLESS / Trojan / VMess 握手校验就会立刻因为时间戳越界而被服务端全部丢弃，表现为全局点测速全红 `Timeout`。

### 第 3 步：更新最新机场订阅并核对节点状态
- 回到小火箭首页，找到你的机场订阅栏，**手指左滑那一行 → 点击“更新”**（或在顶部检查是不是在“设置 → 订阅”关闭了“打开时更新”）。
- 如果在家连着 Wi-Fi 点更新报错 `Network Error` 或拉不下来（被家里光猫拦截订阅域）：临时关闭手机 Wi-Fi，**只用 4G/5G 手机蜂窝网络流量再左滑更新一次订阅**（详情另见 [Wi-Fi vs 移动网络排查](/diagnostics/wifi-ok-or-mobile-fails)）。
- **真测速确认**：更新完后点界面中部的 **“连通性测试”**，在 **“设置 → 测试方法”** 确保选的是 `CONNECT` 或 `HTTP/URL` 测试而非纯 ICMP Ping（苹果环境内 ICMP 极易被防火墙屏蔽产生假超时），挑一个绿色毫秒数的节点选中即可。

### 第 4 步：死守 `全局路由 = 配置（Config）` 与本地 DNS 检查
1. 点击首页 **“全局路由”**，确认为 **`配置 (Config)`**（绝不要长期放在 `代理 Proxy` 或 `直连 Direct` 上；只有在测试排除是不是某条规则误伤某个冷门官网时，才短暂切去 `代理` 验证一分钟后立刻切回）。
2. 如果开启正常但浏览器一直转圈“找不到服务器”：点击底部 **“设置 → DNS”**，若此前手动填过陌生的海外加密 DNS 地址，先试切回**系统默认 / 常规配置**测试；再重启开启飞行模式 5 秒后关闭清空手机 DNS 缓存。

### 第 5 步：关闭苹果系统内部最容易打架的两项功能
- **关闭 iCloud+ 专用代理（Private Relay）**：进入 iPhone“设置 → 顶部您的头像 → iCloud → 专用代理”，确保其处于**关闭**状态，它会在苹果底层与第三方软件争夺加密中转权。
- **重置冲突的系统 VPN 描述文件**：进入手机“设置 → 通用 → VPN 与设备管理 → VPN”，检查里面是不是同时残留了公司办公 VPN、学校 VPN 或者以前装过的旧免费 VPN 软件配置！如有残留可点击详情关闭“按需连接”，保证只有 Shadowrocket 自己那一条 VPN 配置在工作。

### 第 6 步：确认软件版本与机场订阅是否被专属化
- 如果您是通过网上非正规途径用共享账号下载的几年前的**远古旧版小火箭**，它根本解析不了机场近两年新上的 `VLESS-Reality` 或 `Hysteria 2` 节点！务必通过自己安全注册的海外区 Apple ID 在商店将正版 Shadowrocket 更新至最新稳定版（或者使用外区免费正版的 `Karing` / `Streisand` 验证节点本身好坏）。
- 再次核对您购买的品牌是否开放通用订阅：若属于飞猫云、SOGO 云、隐形人等纯专属品牌，请改用官方自带的专属端或参照 [专属端局限说明](/risks/exclusive-client-lockin)。

## 三、修复结果如何快速确认？

完成上述排查后，开启小火箭顶部开关，依次做这三件小事验证全部打通：
1. Safari 打开 `google.com` 或 `wikipedia.org` 秒开；
2. 微信随便发一张图与打开国内 B 站首页依然是原汁原味本省直连秒速；
3. 锁屏待机 5 分钟再解锁亮屏，状态栏右上角或控制中心下拉里的 `VPN` 标识依然稳稳挂着、没有莫名断开掉线。

## 四、常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>小火箭开启后状态栏 VPN 图标一闪而过就自动关闭怎么修？</summary>

大概率超出了 iOS 给第三方 VPN 扩展分配的 50MB 内存上限导致被强杀。请进“配置”页面换用精简的分流配置（删掉几万行的庞大去广告远程规则库与复杂脚本），同时确保未开启重度调试抓包即可稳连。

</details>

<details class="ad-faq-details">
<summary>连通性测试全是黄色或红色超时（Timeout），怎么最快定位？</summary>

依次检查：1）iPhone“设置 → 通用 → 日期与时间”是否开启了自动设置；2）左滑机场订阅更新拉取最新节点列表（连不上 Wi-Fi 就切 5G 更新）；3）进“设置 → 测试方法”确保测的不是易被阻断的 ICMP Ping，以及检查官网面板流量是否已经用完。

</details>

<details class="ad-faq-details">
<summary>小火箭连接显示成功且测出绿字延迟，但就是打不开国外网站怎么办？</summary>

检查小火箭“全局路由”是不是选成了“直连”，改为“配置（Config）”或短暂用“代理”做测试；同时检查 iPhone 设置里是否开着苹果自带的“iCloud 专用代理（Private Relay）”造成网络冲撞；也可开关一次飞行模式清理本地系统 DNS 缓存。

</details>

<details class="ad-faq-details">
<summary>用了小火箭之后国内淘宝、微信和网银变卡还狂耗机场流量是什么原因？</summary>

您一定是误把首页“全局路由”调成了 **“代理（Proxy）”**！立刻改回 **“配置（Config）”** 并选定带大陆直连规则（`GEOIP,CN,DIRECT`）的配置即可恢复国内零消耗秒连。

</details>

<details class="ad-faq-details">
<summary>为什么我借的旧版小火箭导不进机场链接或者新节点显示不支持？</summary>

停留在历史老版本的小火箭核心不支持 VLESS-Reality 与 Hysteria 2 现代协议；请用自己账号在正版商店更新 Shadowrocket 至最新版，或暂时先在外区商店免费下载正版 `Karing` / `Streisand` 导入测试。

</details>
