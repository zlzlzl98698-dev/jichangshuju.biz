# 校园网与企业内网高拦截环境：协议选择、端口穿透与合规边界

> **Answer-First 核心结论**：**在高校校园网或酒店/企业严格受控网络下连不上机场，八成源于出口网关封锁了非标高位端口或截断全部 UDP 流量。** 从协议层面看，**走标准 TCP 443 端口且带有完整 TLS 指纹伪装的 VLESS-Reality 或 Trojan，穿透率显著高于随机大端口 Shadowsocks 与纯 UDP 的 Hysteria 2 / WireGuard**；同时必须配好内网网段直连排除，并在办公环境严格遵守企业 IT 网络合规红线。

---

## 一、高拦截内网常见封锁手段与协议存活对照

学校、医院、机场候机大厅或公司网关，和普通家庭宽带的限制机制完全不同，主要有四道卡口：

| 常见内网拦截策略 | 直接受影响/报错失灵的协议 | 存活率高 / 推荐使用方式 |
|---|---|---|
| **1. 严厉封禁高位 UDP / 防 P2P 限速** | **Hysteria 2**、TUIC、**WireGuard**、OpenVPN UDP（当场无法握手或限速几十 KB） | 切回基于 **TCP** 传输的专线节点（Shadowsocks TCP / Trojan / VLESS-Reality） |
| **2. 端口白名单（仅允许 TCP 80 / 443 等少数标准端口）** | 端口在 `10000–65535` 的常规随机端口节点（全部直接丢包超时） | 寻找节点列表里使用 **`443` 或 `8443` 端口** 的节点（如带 TLS 伪装的 Trojan / WS+TLS / VLESS） |
| **3. 强制门户认证（Dr.COM / 锐捷 Web 登录）** | 还没完成弹框认证就先开 TUN 全局模式 → 死锁转圈 | 先关闭代理 / 设 `campus.edu` 直连完成认证登录，确认内网能打开百度后再打开代理 |
| **4. 透明 DNS 强制劫持（只许内网指定 DNS 服务器出网）** | 外部 DoH/DoT（`https://8.8.8.8`）请求全被丢弃导致客户端 DNS 卡死 | 将客户端 `default-nameserver` / 本地直连 DNS 设回校园 DHCP 自动下发的内网 DNS 地址 |

*(有关各协议底层握手机制的更完整对照见 [VLESS-Reality vs Hysteria 2 与 Trojan 对比](/network/vless-reality-vs-hy2) 及 [常见 VPN 协议解析](/vpn/common-vpn-protocols))*。

## 二、高通过率配置实操 4 步自救

如果你发现自己处在只能开网页端口或频繁掉线的校园网 Wi-Fi 下，按这四步调整客户端与挑选线路往往立刻见效：

### 1. 关闭系统代理干扰，优先通过校园网认证关
- 使用 **[Clash Verge Rev](/clients/clash-verge)** 或手机端时，断网重连第一动作永远是 **先关掉“系统代理”和“TUN 模式”**；
- 在浏览器认证成功后再启动代理（详细教程参考 [Wi-Fi 连不上而手机流量可以排查](/diagnostics/wifi-ok-or-mobile-fails)）。

### 2. 检查目标机场有没有提供“TLS / 443 端口 / 伪装兼容协议”
并非所有写着“全能专线”的机场在端口配置上都友好：
- 纯粹跑五位数端口 `Shadowsocks` 的旧式专线，在普通家宽上快如闪电，到了仅放行 80/443 端口的严格专网却可能全军覆没；
- 选择同时保留 **Trojan / VLESS-Reality（走 TCP 443）或 WebSocket+TLS 443 备用入口** 的机场（购前务必看清品牌支持的 [协议矩阵与客户端兼容表](/database/clients)），抗内网拦截概率会高出很多。

### 3. 给校内域名与内网网段加上 `DIRECT` 白名单
如果你经常边开代理边查知网/学校图书馆/教务系统，或登录路由器后台，在 Clash Verge Rev 的 [Merge / Script 覆写模板](/guides/clash-verge-merge-script) 头部补充强直连规则：
```yaml
prepend-rules:
  - DOMAIN-SUFFIX,edu.cn,DIRECT
  - IP-CIDR,10.0.0.0/8,DIRECT,no-resolve
  - IP-CIDR,172.16.0.0/12,DIRECT,no-resolve
  - IP-CIDR,192.168.0.0/16,DIRECT,no-resolve
```
*(提示：`edu.cn` 走校园内网免流量且免走外网，能防止拉爆账号流量和教务 IP 鉴权错误)*。

### 4. 处理免费校园 IPv6 导致的“假超时”
部分高校只给未付费账户开放 IPv6、或 IPv6 路由与机场软件内置规则冲突：尝试在代理软件设置中临时 **关闭 `IPv6: false`**，有时所有网页立刻恢复顺畅（更多相关诊断见 [连上节点却打不开网页排查](/diagnostics/connected-but-no-internet)）。

## 三、公司企业办公内网的特别合规与风控警告

> **重要提醒**：**家庭/宿舍网络与“公司管理资产/办公内网”性质完全不同！**

1. **禁止在受控办公设备私装未授权第三方软件**：许多公司终端预装了安全准入代理、EDR/DLP 防泄漏审计，甚至会对流量做企业中间人 HTTPS 证书解密；在此环境下强行跑个人加密代理软件不仅容易被直接阻断封端口，还极易触发内网信息安全合规告警；
2. **区分“自己手机热点/个人笔记本”与“公司网络”**：在工作场所如需查阅合法外部资料或受限开发文档，优先通过公司 IT 审批的合规办公网关解决，或使用自费流量手机热点连接个人自带设备处理私人事务。

## 四、常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>为什么宿舍校园网或公司 Wi-Fi 下所有机场节点突然全部超时，换手机热点就秒通？</summary>

这是因为校园或企业出口防火墙阻断了非标准高位端口、掐断了大流量 UDP（影响 Hysteria 2/WireGuard）或劫持了客户端的加密 DNS 请求。

</details>

<details class="ad-faq-details">
<summary>在高拦截、只放行常见网页端口的网络里，哪类代理协议的穿透通过率最高？</summary>

优先选择基于 **TCP 443 端口的 VLESS-Reality 或 Trojan / WS+TLS**，因为其传输端口与握手外观与正常访问 HTTPS 网站高度接近。

</details>

<details class="ad-faq-details">
<summary>校园网连不上代理，有时候并不是协议被封，而是认证网关或 IPv6 抢道？</summary>

是的。没过锐捷/Dr.COM 门户认证就先开 TUN 代理会导致死锁认证失败；校园网下关闭客户端 IPv6 转发并把 `*.edu.cn` 设为直连通常很有效。

</details>

<details class="ad-faq-details">
<summary>在公司办公电脑或工作内网使用个人机场代理，有哪些不可忽视的安全与合规边界？</summary>

严禁绕过公司安全网关规定在受监控的公司电脑运行个人代理软件，避免触发数据防泄密审计与合规风险；企业内部开发查阅请按正常 IT 流程申请。

</details>

<details class="ad-faq-details">
<summary>怎么在客户端设置里让校园网认证、学校教务系统或公司内网不受机场代理干扰？</summary>

使用 Rule（规则）模式并前置写入 `*.edu.cn` 与三大私网 IP 段直连（`DIRECT`）即可保证内网高速访问且不消耗机场付费流量。

</details>
