## 一、自研专属客户端边界与“软路由歧义”实话实说

这是评估 SOGO 云时最容易让技术向玩家产生误解的地方：
- 一方面，宣传文案里列出了 `Windows / macOS / iOS / Android 与主流软路由方向`；
- 另一方面，核心字段明确锁定：**`仅支持自研客户端，不提供第三方订阅链接`**（`thirdPartySupport: no`）。

**实务结论**：只要一家机场不向外部开放标准 Clash YAML / V2Ray / sing-box 订阅链接，那么无论是您手上的 iPhone [Shadowrocket（小火箭）](/clients/shadowrocket)、桌面 [Clash Verge Rev](/clients/clash-verge)，还是常见的通用 [OpenWrt 软路由插件](/guides/router-openwrt)，都无法按通用方式自行导入配置！因此对第三方工具自由度敏感的买家，务必把它当作纯专属客户端服务来权衡（对比可选 [光速云](/brands/guangsuyun) 或 [星岛梦](/brands/xingdaomeng)）。
