# 纠错机制与数据更新记录

> **Answer-First 核心规范**：**机场套餐定价、优惠码限制、节点解锁表现与客户端订阅政策随时处于动态变化中；本站不接受任何口头臆测修改，所有纠错更新均须附带可核查的时间戳与来源证据，并在发布时同步记入下方公开验证日志。**

---

## 一、五步数据纠错线索提交规范

如果发现任意品牌页面、套餐计算器或对比矩阵中的数据已与官方最新页面产生偏差，请按以下五项要素整理核查材料提交修正线索：

1. **涉事品牌与页面 URL**：准确指出品牌实体 ID 或具体页面路径（例如 `/brands/guangsuyun/plans` 或 `/compare/weitu-vs-firefly`）；
2. **变更的具体数据字段**：说明发生变动的字段名称（如月付实付价变化、原优惠码失效或新增限制条款、从开放第三方订阅改为纯专属客户端等）；
3. **带清晰日期的佐证材料**：提供包含官方域名与当前系统时间的水印或完整结账页截图；若提交测速更新，须保留测试日期、接入带宽、测速线程与节点全称，严禁裁剪时间戳；
4. **冲突保留还是覆盖原则**：若新证据证实官方已明确改版（如 2026-10 多家转向专属客户端），旧口径将标为 `expired` 归档保留轨迹；若存在多处官方描述互相抵触，则新增编号写入 [`CF` 冲突台账](/methodology/sources)；
5. **复核窗口期说明**：收到更新后统一先更新 `data/brands/`、`data/plans/` 等结构化主数据源，经 `npm run validate && npm run qa` 全站联动校验无冲突后一次性静态重构建发布。
