# 评测方法与数据可信度分级

> **Answer-First 核心原则**：**机场数据绝不生成脱离测试环境和时间的“主观 4.9/5 星级评分”或虚假用户评价，而是对每一条价格、测速、协议、设备限制与解锁结论实施“字段级来源标记”与“冲突并列披露”。**

---

## 一、八种字段数据状态定义

全库品牌档案与对比表格对单个事实字段均适用以下八类状态口径：

| 状态标记 | 含义与准入条件 | 典型站内案例 |
|---|---|---|
| **`measured`（独立实测）** | 附带可核查测试日期、网络环境、测速客户端与完整节点列表的原图实证 | 光速云 `2026-08-19` 五张 MiaoKo 截图（含长沙电信、广西移动、河北联通、珠海联通 9Gbps） |
| **`historical`（历史记录）** | 留存过的历史测试快照或早期批次汇总记录，但近端时效性需用户重测确认 | `2026-08-11` MAI-TEST-BOT 图包；灵动云、浪网 `2026-08-09` 历史存档 |
| **`vendor`（品牌方声明）** | 来自服务商官方简介、套餐卡片或宣传口径的单方陈述，未经第三方长期压测 | “2000Mbps 带宽”“晚高峰不限速”“支持 AI/流媒体全解锁”“1 小时修复”等 |
| **`third-party`（第三方资料）** | 引自开源客户端 GitHub 仓库说明或已核实技术文档规范 | Clash Verge Rev (Mihomo)、sing-box `.srs` 规则集与 OpenWrt 24.10+ nftables 依赖 |
| **`pending`（待核实）** | 原始材料未提及或官网未公开的关键运维参数 | 部分品牌同时在线设备数限制、节点流量倍率、第三方订阅开关或退款规则 |
| **`conflict`（来源冲突）** | 不同原始资料段对同一品牌的参数、优惠码、协议或链接存在直接矛盾 | `CF-001` 光速云轻量版 59GB vs 69GB；`CF-003` 微风 7元 vs 137元等 18 项 |
| **`expired`（已过期）** | 明确被服务商新版政策取代、仅留作历史背景对照的旧口径 | Firefly、无忧链接、灵猫网络于 `2026-10` 切换为纯官方专属客户端前的旧订阅说明 |
| **`untested`（未测试）** | 当前批次未开展专门检测的项目，严格保留留空 | 缺独立测速图的 10 家品牌及部分未逐一验证的冷门流媒体地区 |

## 二、资料完整度（`completenessScore`）≠ 推荐或安全评分

页面上展示的百分比（例如光速云 **96%**、Firefly **84%**、星岛梦 **80%**、浪网 **40%**）采用客观字段覆盖度计算：
1. **核查维度**：涵盖多档价目表、优惠码限制说明、线路与底层协议、节点覆盖列表、独立 PNG 测速与地区表、AI/流媒体验证、客户端兼容模式、设备限额、流量倍率、支付方式与退款条约等公开可查字段比例。
2. **严格边界**：高完整度只说明“该品牌目前公开可审计资料非常充实，买前盲区较少”，**不代表它必然更快、更便宜或永不故障**；反之，低完整度只说明“存在较多黑盒缺口”，此时用户不应未经单月小额验证直接购买长期年付。

## 三、测速图审计与单价计算口径

- **测速审计规范**：统一标注测试工具（MiaoKo / MAI-TEST-BOT）、接入端口带宽（如 2Gbps / 5Gbps / 9Gbps）、单线程与多线程区别，并单独标注“非晚高峰单日截面不可直接等同 21:00–23:00 全网稳态”。
- **异常报错不掩盖**：如飞猫云 `08-11` 图存在平均速度列 `595MB` 级脚本显示 bug、光速云 `08-19` 图展示了个别冷门节点掉速或 `HK02` 零速度节点，本站全部原文保留并在评测正文中直接指明，不作裁图美化。
- **单位成本算账公式**：周期套餐按 `实付金额 ÷ 计费月数 ÷ 月配额 GB`，不限时按 `实付 ÷ 总 GB`，详见 [每 GB 流量成本模型](/pricing/traffic-cost) 与 [套餐成本计算器](/database/plans)。
