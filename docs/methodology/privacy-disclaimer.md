# 隐私政策与免责声明

> **Answer-First 核心承诺**：**机场数据（`jichangshuju.biz`）采用 100% 纯静态 HTML 架构构建，不提供用户账户注册、不保存任何访客身份信息，更绝不接触、抓取或储存任何用户的个人机场订阅 URL、代理节点密钥或翻墙浏览记录。**

## 一、隐私保护与数据处理边界

1. **无服务端个人数据收集**：
   - 全站由 VitePress 编译输出静态文件部署于 Apache 静态目录，后台无会员数据库、无登录 Cookie 跟踪；
   - 全站目前未植入任何第三方广告联盟跟踪脚本或跨站个人画像 ID。
2. **本地交互计算与关键词工具全在浏览器完成**：
   - 无论是在 [套餐数据库计算器](/database/plans) 输入自定义预算和流量参数，还是在 [多品牌对比工具](/compare/) 或 [关键词控制台](/database/keywords) 勾选过滤条件，所有计算均完全在访问者本地设备浏览器内存中完成，零数据外传。
3. **出站跳转点击事件（Telemetry）安全说明**：
   - 当访问者主动点击带有 `商业推广入口` 标记的出站按钮时，界面会在浏览器本地 `localStorage` 仅保留匿名的站内路径来源与品牌 ID 统计计数（用于评估站点内部栏目效能），不包含任何 IP、账号或浏览器指纹信息，访问者可随时清除浏览器本地存储数据。
4. **外部网站独立隐私权责**：
   - 点击外部服务商或 GitHub 开源仓库链接后即离开本域名；各外部服务商官网的注册、实名或支付记录均受目标网站自身的隐私条款约束，本站无法也无权干涉其内部账单与订阅系统。
