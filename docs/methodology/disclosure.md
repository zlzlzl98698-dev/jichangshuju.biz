# 商业推广披露声明（Affiliate Disclosure）

> **Answer-First 核心声明**：**机场数据（`jichangshuju.biz`）通过合规商业推广合作维持服务器运营与长期数据审计，本站核心合作品牌为光速云，其次依合作顺位展示暮光加速、飞猫云、微风网络、大佬云、星岛梦、隐形人、二猫云、无忧链接、唯兔云与 Firefly。商业合作不影响用户支付价格，也绝不干预实测缺点与冲突记录的客观披露。**

## 一、四条不可逾越的商业合规防线

1. **全站出站链接属性强制锁定**：
   - 所有合作品牌注册入口统一从单一数据源 `data/affiliate-links.json` 注入到 `AffiliateCtaCard.vue` 组件中；
   - 每个商业出口标签强制包裹 `target="_blank" rel="nofollow sponsored noopener"`，并在按钮紧邻区域以清晰文字展示“含推广链接，通过链接注册可能为本站带来佣金，不影响用户支付价格”。
   - 站内正文引用原始排查域名案例时一律采用纯文本代码块隔离，严禁出现未标记 `nofollow` 的裸外部商业外链（已纳入 `npm run qa` 强制构建拦截项）。
2. **合作顺位 ≠ 测速或综合性能排名**：
   - 合作顺位仅体现在首页“精选合作品牌”区块与品牌清单默认呈现顺序上；
   - 在 [机场推荐排行口径](/recommend/rankings)、[每 GB 成本计算器](/database/plans) 与 [多品牌参数对比工具](/compare/) 中，所有品牌均按真实完整度、每 GB 成本、客户端开放程度及各自客观指标平权对照，不存在“花钱买第一”。
3. **缺点、异常与局限一视同仁公开**：
   - 即使是核心推广品牌**[光速云](/brands/guangsuyun)**（96% 完整度），本站依然在首屏下方如实列出 `CF-001`（59GB vs 69GB 口径分歧）、`08-19` 截图中德国冷门节点掉速及部分新加坡/台湾节点送中记录、香港专线不支持网页版 ChatGPT/Gemini、以及“无试用、特殊商品不支持退款”条款，绝不隐藏负面细节。
4. **绝不张冠李戴或虚构无依据入口**：
   - 对缺乏核实注册网址、或链接存在格式缺陷的品牌（例如 `CF-013` 云界线、`CF-014` 环球梯缺少 `#/` 路径），保留预警提示框；严禁在无官网入口页偷偷替换为其他品牌的推广跳转链接。

## 二、纯粹技术排障页面的边界克制

依据站内内容准则，面向纯操作排错的技术指南页面（包括但不限于 Clash TUN 模式冲突、Clash Verge 无法启动白屏、HTTP 200 空订阅节点排查、YouTube 4K 卡顿与送中修复、Wi-Fi 与手机流量通断差异排查等）专注于定位网络和系统报错原因本身，**不强行嵌入与排错无关的品牌广告与推广卡片**。
