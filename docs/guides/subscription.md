# 机场订阅导入教程与新手入门（Clash / v2rayN / Shadowrocket / 专属端）

**买完机场套餐准备上手连网时，第一步千万别急着到处找软件——先看一眼你买的品牌属于“开放第三方通用订阅”还是“仅限官方自研专属端”。前者只需要把后台的订阅地址复制进 [Clash Verge Rev](/clients/clash-verge)、[v2rayN](/clients/v2rayn) 或 [Shadowrocket](/clients/shadowrocket)；后者更简单，只需去官网下载对应系统的品牌专属 App 输入邮箱和密码直接登录。**

---

## 一、先分清您的机场属于哪一条路线（对照全库规则）

| 接入路线 | 典型代表品牌 | 操作核心动作 | 优势与局限 |
|---|---|---|---|
| **路线 A：开放第三方通用订阅**（支持多软件/软路由） | **[光速云](/brands/guangsuyun)**（双端均支持）、**[星岛梦](/brands/xingdaomeng)**、**[暮光加速](/brands/muguang)**、**[一翻云](/brands/yifan)**、**[二猫云](/brands/ermao)**、**[梯子云](/brands/tiziyun)**、**[唯兔云](/brands/weitu)** | 在官网仪表盘复制“Clash / V2Ray / 小火箭订阅地址”，粘贴到正版开源客户端中导入 | **自由度高、可装软路由、可自定义分流规则、不被单一厂商软件锁定** |
| **路线 B：仅限品牌自研专属客户端** | **[飞猫云](/brands/feimao)**、**[SOGO 云](/brands/sogo)**、**[隐形人](/brands/yinxingren)**、**[无忧链接](/brands/wuyou)**、**[Firefly](/brands/firefly)** | 在机场官网直接下载其官方 `.exe` / `.dmg` / `.apk` 程序，打开后像登普通社交软件一样输入账号密码 | **零门槛一键即用**，无需学导入教程；但无法在 OpenWrt 软路由或第三方端上运行 |

*(注：如果您还没下载好正版开源客户端，请先前往 [全平台客户端软件目录](/clients/) 按 Windows / Mac / Android / iOS 找准官方发布源下载，切勿在搜索引擎随便下山寨包。)*

## 二、标准导入四平台实战分步动作

若您的品牌属于**路线 A（开放通用订阅）**，请按您手中的设备对号入座操作：

### 1. Windows / macOS 电脑端 —— Clash Verge Rev / FlClash
1. 打开机场官网“仪表盘” → 找到“一键导入”按钮（若弹出浏览器提示打开软件，点击允许即自动完成）或手动点击 **“复制 Clash 订阅链接”**。
2. 打开已安装的 **Clash Verge Rev**，点击左侧菜单栏的 **“订阅 (Profiles)”**。
3. 把链接粘贴到顶部白色输入框中，点击右侧 **“导入 (Import)”**；等待提示导入成功后，**鼠标单击刚才出现的新卡片框使其高亮选中生效**。
4. 切回左侧 **“代理 (Proxies)”** 确认顶部模式处于 **`Rule`（规则模式）**，随后点击左侧 **“设置 (Settings)”** 将 **“系统代理 (System Proxy)”** 开关向右打开变为高亮激活即可开启冲浪！

### 2. Windows 老牌极客端 —— v2rayN
1. 在机场后台复制 **“通用 / V2Ray / Base64 订阅链接”**（不要选 Clash YAML 链接）。
2. 启动 v2rayN（务必使用官方 `With-Core` 全量包），点击顶部菜单栏 **“订阅分组” → “订阅分组设置” → “添加”**。
3. 填入任意备注名称、在 `Url` 栏粘贴订阅地址后点击确定。
4. 返回主界面点击顶部 **“订阅分组” → “更新全部订阅（不通过代理）”**；出现节点后按 `Ctrl+A` 全选并按 `Ctrl+R` 测试真延迟，选一个绿色有效节点按回车选中，最后把左下角系统代理设为 **“自动配置系统代理”**。

### 3. iPhone / iPad 苹果端 —— Shadowrocket（小火箭） / Karing
1. 使用外区 Apple ID 安装好正版 [Shadowrocket（小火箭）](/clients/shadowrocket) 或免费的 `Karing`。
2. 在手机 Safari 浏览器打开机场官网点击“一键导入 Shadowrocket”自动拉起；若手动添加，则先复制通用订阅链接，打开小火箭点右上角 **`+`** 号 → 第一行类型务必改成 **`Subscribe`（订阅）** → 在 URL 栏粘贴链接并点击右上角完成。
3. 回到首页确保“全局路由”选的是 **`配置（Config）`**，点击“连通性测试”挑一个延低绿色节点选中，打开顶部第一个连接开关并在 iOS 弹出“添加 VPN 配置”系统框时输入锁屏密码/面容授权即可。

### 4. Android 安卓手机端 —— v2rayNG / FlClash
1. 用 **v2rayNG**：点击左上角菜单 → **订阅分组设置** → 右上角 `+` 添加通用订阅链接并保存，回到主界面点右上角三点菜单 → **更新订阅**，选中绿色有效节点后点右下角圆形启动图标。
2. 用 **FlClash**：逻辑与桌面 Clash Verge Rev 几乎完全一致，贴入 Clash 订阅地址导入选中，回到首页大按钮开启即可（别忘了进手机电池设置关闭省电杀后台限制，详见 [安卓客户端避坑指南](/clients/android)）。

## 三、连网后 30 秒必做的三项初次体检

不管您用了哪款客户端，成功连上后请养成习惯花 30 秒核查以下三项，能免掉后期 90% 的莫名翻车：

1. **检查是不是开成了“全局（Global）”**：务必确保工作模式显示为 **`Rule`（规则 / 绕过大陆）**。验证方法：打开任意国内测速或百度 `ip`，显示的应当是您自己原本所在的国内城市宽带 IP，同时打开 Google 又能顺畅加载，这才代表国内外分流真正健康。
2. **开启“自动更新订阅”开关**：机场有时会遭遇临时入口维护或增加新线路，在客户端设置打开每 12–24 小时或打开软件时自动更新一次订阅，保证节点始终是最新鲜的可用 IP。
3. **测试 AI 或流媒体需切换出香港**：如果发现打开 ChatGPT 提示不受支持，别以为软件坏了，回到客户端节点列表换成**新加坡、日本或美国**再试（详见 [AI 节点选区指引](/streaming-ai/chatgpt)）。

## 四、信息边界与诚实披露

- **专属端与通用端的动态切换**：极少数品牌（例如部分档案里记录的 Firefly、无忧链接、灵猫网络在 `2026-10` 前后调整过客户端策略）会随风控升级收紧或变更通用订阅政策。如果在某个品牌官网发现以前有的导入按钮消失了，请以该品牌官网最新公告或工单说明为准。
- **排错兜底资源**：如果您卡在第二步“订阅怎么都拉不下来”，或全部节点延迟一排全红 `Timeout`，请不要反复卸载重装软件，立刻转入对应的诊断页排查。

## 五、常见问题（FAQ）

<details class="ad-faq-details" open>
<summary>买完机场后台找不到 Clash 订阅链接或导入按钮怎么办？</summary>

首先确认该品牌是否支持通用第三方客户端（例如飞猫云、SOGO 云、隐形人等纯专属品牌后台不开放订阅地址，必须使用官网下载自研专属 App）。确认是支持第三方导入的品牌后，在仪表盘仔细查找“复制订阅 / 一键导入”菜单即可。

</details>

<details class="ad-faq-details">
<summary>导入订阅提示“Fetch failed”或节点为空怎么办？</summary>

检查复制地址有没有带多余换行空格、链接格式与客户端是否匹配（Clash 对应 YAML，v2rayN 对应 Base64），或者是否因机场主默认订阅域被本地直连网络污染导致无法拉取。遇到拉取失败请参照 [机场订阅失败排查](/diagnostics/subscription-failed)。

</details>

<details class="ad-faq-details">
<summary>节点已经导进去了且测出有绿字延迟，为什么浏览器还是打不开外网？</summary>

绝大多数是漏了打开核心连接总开关：在电脑端必须把“系统代理（System Proxy）”开关打开（或开启 TUN 模式）；在手机端必须打开软件主页面的运行总开关并授予系统 VPN 连接确认权限。

</details>

<details class="ad-faq-details">
<summary>机场同时提供了好几种格式的订阅，应该复制哪一条？</summary>

Clash Verge Rev / FlClash / OpenClash 选用标有 **Clash** 的订阅；v2rayN / v2rayNG 选用 **V2Ray / Base64 通用** 订阅；iOS Shadowrocket 两者均可识别，优先使用专属一键导入按钮或通用订阅。

</details>

<details class="ad-faq-details">
<summary>订阅地址链接能不能在群里发给同学一起拼单？</summary>

强烈不建议！订阅 URL 包含账户核心鉴权秘钥，泄漏等于交出账户全部使用权，且同时间多地域、多设备异地高频并发刷新极大概率触发机场安全系统封号清理。

</details>
